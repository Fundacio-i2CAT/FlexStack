# Decentralized Environmental Notification (DEN) Service

The present DEN Service is implemented following the **ETSI TS 103 831 V2.3.1 (2025-11)** standard (latest version; DENM-PDU-Descriptions v2.3 over CDD v4.3), including DENM update, termination (cancellation and negation), repetition, the originating and receiving ITS-S message tables and the optional Keep-Alive Forwarding.
